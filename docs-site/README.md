# Horizon docs site

The Astro Starlight docs site for `@theproductiveschedule/horizon-design-system`, live at **https://horizon-docs-alpha.vercel.app**.

It lives only on the `astro` branch. The `horizon-docs` Vercel project builds this folder (`docs-site/`) and deploys every push to `astro` to production. Never deploy it by hand, and never merge `astro` into `main`.

## What is generated and what is written

| Generated by `scripts/generate.mjs` — never edit by hand | Written from the repo, checked every run |
|---|---|
| `src/content/docs/index.mdx` | `get-started/versioning.md`, `get-started/upgrading.md` |
| `src/content/docs/core/components/*` | `designing/introduction.md` |
| `src/content/docs/core/tokens.md` | `developing/introduction.md`, `developing/react.md`, `developing/react-router.md` |
| `src/content/docs/get-started/changelog.md`, `roadmap.md`, `news.md` | `skills/knowledge-skill.md`, `styling/theming.md` |
| `src/styles/tokens.generated.css` | `help/*.md` |

The generator reads:

- the design system repo at a pinned commit, passed as `--repo` (with `npm run build:package` already run there);
- `sources/registry-status.json` — the registry's component names and statuses, read by doc-generator, no IDs;
- `sources/figma.json` — each component's Figma description and variant properties, read by doc-generator;
- `reference.config.json` — the site, Storybook and repo URLs, and embed heights;
- the deployed Storybook's `index.json`, and `npm view` for publish dates.

A component gets a page only if the registry reads `Completed` or `Released`, its release verdict is `Cleared`, and it is exported from `src/index.ts`.

## Run it

```bash
npm ci
node scripts/generate.mjs --repo ../path/to/horizon-design-system   # regenerate the reference pages
npm run dev                                                          # http://localhost:4321
npm run build                                                        # static output in dist/
```

## Structure

The sidebar is written out in `astro.config.mjs`, so a missing page fails the build: Get Started, Designing, Developing, Skills, Core (Components, Tokens), Styling, Help. `redirects` there keeps old URLs recorded in the registry's `Astro Link` working.

The site wears Horizon's own tokens: `src/styles/reference.css` maps Starlight's variables onto them, and Inter is self-hosted from `@fontsource/inter`, because the site's Content Security Policy (`vercel.json`) allows fonts from `'self'` only.

The rules for building it are in `.claude/skills/astro-page/SKILL.md` on `main`.

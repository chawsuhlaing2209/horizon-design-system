### Use when

<ul><li>{"Buttons communicate actions that people can take. They are typically placed throughout the UI, in places like: Dialogs, Modal windows, Forms, Cards, Toolbars"}<br />{"They can also be placed within standard button groups."}</li><li>{"Use visually-prominent filled buttons for the most important actions"}</li><li>{"Use buttons for discrete actions."}</li><li>{"A button container’s width is dynamically set to fit its label text"}</li><li>{"Button container width can be responsive, which allows it to stretch horizontally"}</li></ul>

### Don't use when

<ul><li>{"Don’t clutter your UI with too many buttons. Consider presenting low-priority actions in overflow menus or as icon buttons."}<br /><em>{"Alternative: "}</em>{"overflow menus or as icon buttons"}</li><li>{"A button container’s width shouldn’t be narrower than its label text"}</li><li>{"Don’t wrap text. For maximum legibility, label text should remain on a single line."}</li></ul>

### Best practice

<ul><li>{"Use sentence case for button label text, capitalizing the first word and proper nouns"}</li><li>{"Buttons can move in the layout, but elements should remain in the same order"}</li></ul>
